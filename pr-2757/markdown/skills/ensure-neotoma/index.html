## Workflow

1.  1
    
    Check CLI availability
    
    Runs \`npx neotoma status\` to detect installation status
    
2.  2
    
    Install if needed
    
    Guides \`npm install -g neotoma\` when the CLI is not found
    
3.  3
    
    Run setup
    
    Executes \`neotoma setup --yes\` to configure MCP, hooks, and permissions
    
4.  4
    
    Verify connectivity
    
    Calls \`get\_session\_identity\` to confirm the MCP connection is live
