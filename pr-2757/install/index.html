Optional Claude Code command permissions

This optional snippet writes to the target file below. Broad Neotoma command approvals, including Claude Code's Bash(neotoma:*) and Cursor or Codex neotoma *, can permit any Neotoma subcommand, including reset, without another host prompt. Review their full scope before copying. If permission is refused or its scope is unknown, inspect the host setting instead of widening access automatically.

Claude Code permissions

JSON merge into Claude Code's permissions file. Target: .claude/settings.local.json (project) — or ~/.claude/settings.json (user)

// Paste into .claude/settings.local.json (project) or ~/.claude/settings.json (user).
// Merge with any existing "permissions.allow" list.
{
  "permissions": {
    "allow": [
      "Bash(neotoma:*)",
      "Bash(npm install -g neotoma:*)"
    ]
  }
}
