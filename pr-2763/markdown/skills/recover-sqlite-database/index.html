## Workflow

1.  1
    
    Check integrity
    
    Run \`PRAGMA integrity\_check\` on the database
    
2.  2
    
    Run recovery
    
    Execute \`.recover\` to extract data from corrupted pages
    
3.  3
    
    Swap database
    
    Guide user through replacing the corrupted file
