Entorno público de pruebas de Neotoma

Sin instalaciónSesiones efímerasDatos públicos

El entorno de pruebas es una instancia pública de Neotoma en este servidor. Cualquier agente puede leer y escribir sin instalar Neotoma localmente. Sirve para comprobar en menos de un minuto si Neotoma funciona con tu entorno de agentes, ver la interfaz Inspector con datos reales y compartir ejemplos reproducibles.

¿Prefieres una instancia privada? Instala Neotoma localmente. El entorno público solo es adecuado para hacer pruebas.

Lo que debes saber

  • !Los datos son públicos. Todas las entidades, observaciones y archivos subidos son visibles para los demás usuarios. No guardes datos personales, credenciales, datos de producción ni nada que no publicarías en un gist público.
  • ↻Los datos son efímeros por sesión. Tu espacio de trabajo se elimina definitivamente al caducar la sesión (hasta 7 días, con límite el domingo a las 00:00 UTC), al terminarla o reiniciarla, o cuando se ejecute el barrido en segundo plano. Trátalo como espacio temporal, no como almacenamiento.
  • →Los endpoints administrativos destructivos están deshabilitados. Se bloquean las fusiones, divisiones, reescrituras de esquema y nuevos cálculos de instantáneas de todo el corpus para que nadie destruya la demostración de los demás. Las eliminaciones reversibles siguen disponibles.
  • -Condiciones de uso: antes de escribir, los agentes deben leer las condiciones del entorno de pruebas en este sitio (el mismo texto que devuelve GET https://sandbox.neotoma.io/sandbox/terms en JSON).

Conecta tu agente

Conexión mediante agente: pega estas instrucciones en el agente que quieras conectar. Editará la configuración MCP y hará una comprobación básica.

Code snippet

Conecta este servidor MCP de Neotoma por mí: https://sandbox.neotoma.io/mcp

Es un entorno de pruebas público con espacios de trabajo efímeros por sesión. Todo lo que guarde será visible públicamente y se eliminará definitivamente cuando caduque mi sesión (hasta 7 días, con límite el domingo a las 00:00 UTC), cuando termine o reinicie la sesión, o antes mediante el barrido en segundo plano. Úsalo solo para probarlo: no guardes nada privado ni dependas de la persistencia de los datos.

Añade el servidor a la configuración MCP de mi herramienta actual y confirma que responde con una sola llamada de consulta.

Cursor

Añade esto a .cursor/mcp.json y reinicia Cursor:

Code snippet

{
  "mcpServers": {
    "neotoma-sandbox": {
      "url": "https://sandbox.neotoma.io/mcp"
    }
  }
}

Claude Code

Registra el servidor remoto desde la CLI:

Code snippet

claude mcp add neotoma-sandbox --transport http --url https://sandbox.neotoma.io/mcp

Para otros entornos, consulta la guía de conexión por herramienta, con vías específicas para Claude Desktop, ChatGPT, Codex y OpenClaw. La página principal del entorno activo también ofrece un selector con fragmentos listos para copiar y con el servidor correcto.

Informa de abusos o datos problemáticos

Como el entorno es público, alguien puede guardar contenido indebido. Los avisos llegan a una cola de moderación y, cuando se confirman, provocan un reinicio anticipado de la entidad afectada o de todo el conjunto de datos.

  • Envía POST /sandbox/report con reason y description (los agentes pueden usar el flujo de herramientas MCP).
  • O usa el botón de denuncia de cualquier entidad en Inspector.

Cuándo conviene instalar Neotoma localmente

El entorno público sirve para evaluar y compartir ejemplos. Para cualquier otro uso, instálalo localmente:

  • Quieres conservar tus registros más allá del domingo.
  • Tienes datos privados: clientes, finanzas, correspondencia personal o contexto de código.
  • Necesitas operaciones administrativas destructivas: fusión, división o nuevo cálculo completo.
  • Quieres latencia predecible y un Inspector privado.
