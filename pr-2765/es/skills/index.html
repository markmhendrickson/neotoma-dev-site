Instalar skills

Las skills se distribuyen con el paquete npm neotoma. Ejecutar neotoma setup las instala automáticamente en tu entorno de agente.

npm install -g neotoma
neotoma setup --yes

También puedes pedir a tu agente: «Ejecuta la skill ensure-neotoma».

Todas las skills son de código abierto

Consulta los archivos SKILL.md en el directorio skills/ de GitHub. También puedes encontrar skills en SkillHub.
