Remember Contacts

Build a unified, deduplicated contact list from email headers, calendar attendees, chat participants, vCard files, and LinkedIn exports. Merges duplicates by email and name to create a comprehensive contact graph.

Skill instructions

Consolidate contacts from multiple sources — email, calendar, chat, vCards, LinkedIn exports — into Neotoma memory. Deduplicates by name and email to build a unified contact graph. When the user wants to build a persistent, deduplicated contact list from various data sources.
