# Install options

Takes a few minutes

Choose the AI tool you use. The selected path shows how to connect it to a Neotoma instance, how to check the connection, and the matching guide. Local setup, authenticated remote access, native plugins, SDK adapters, and registries have different prerequisites.

**Before you begin:** a local package install adds a CLI; initialization creates configuration and local databases. Host setup can change permission files or enable later capture, and update checks can contact the npm registry. A remote client can instead use an existing authenticated endpoint without a local Neotoma install. Review the complete [system changes, reset limits, and permission effects](/install/system-changes/) before copying a step.

## Optional Claude Code command permissions

This optional snippet writes to the target file below. Broad Neotoma command approvals, including Claude Code's `Bash(neotoma:*)` and Cursor or Codex `neotoma *`, can permit any Neotoma subcommand, including reset, without another host prompt. Review their full scope before copying. If permission is refused or its scope is unknown, inspect the host setting instead of widening access automatically.

Copy

Claude Code permissions

JSON merge into Claude Code's permissions file. Target: .claude/settings.local.json (project) — or ~/.claude/settings.json (user)

```
// Paste into .claude/settings.local.json (project) or ~/.claude/settings.json (user).
// Merge with any existing "permissions.allow" list.
{
  "permissions": {
    "allow": [
      "Bash(neotoma:*)",
      "Bash(npm install -g neotoma:*)"
    ]
  }
}
```
