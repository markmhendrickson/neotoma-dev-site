Base SQLite de Neotoma

Procedimiento

  1. 1

    Comprobar integridad

    Ejecuta `PRAGMA integrity_check` en la base de datos.

  2. 2

    Recuperar datos

    Ejecuta `.recover` para extraerlos de las páginas dañadas.

  3. 3

    Sustituir la base

    Guía la sustitución del archivo dañado por el recuperado.
